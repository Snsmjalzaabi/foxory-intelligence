# Contributing

Use a development branch and a focused pull request. Explain the user-visible change, trust boundaries, verification performed and limitations. Run backend tests, the TypeScript production build and relevant browser tests. Do not claim unavailable hardware or live integration checks passed.

Keep secrets, personal records, model weights and local configuration out of Git. Verify dependency/model licenses and attribution before distribution. Add migrations rather than modifying user databases implicitly. Introduce no external side effects, paid provider defaults, public deployment or agent permission escalation without an explicit design and tests. See SECURITY.md for private reporting.

Contributions should be original or appropriately licensed for Apache-2.0 distribution. Do not copy proprietary interfaces or undocumented APIs.
