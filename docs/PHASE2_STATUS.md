## Security and operational limits

One API process/replica is required. Default Wikipedia search has encyclopedia-only breadth; SearXNG integration is fixture-tested, not verified against a live configured instance. Claim verification/credibility/conflict interpretation remains heuristic; source integrity is not truth verification. Parser uploads require Linux/libseccomp; no unsafe Windows/macOS native fallback. Docker instructions exist for those systems but were not executed there. Embeddings use bounded JSON vectors rather than pgvector. Real parallel council, GPU, reference RTX 3060 performance and broad answer-quality benchmarks remain unverified. The HTTP proxy TLS adapter relies on pinned httpcore internals and requires retesting before dependency upgrades. The sandbox reduces exposure but is not an independent security certification. Host/disk encryption, TLS for public hosting, comprehensive malware scanning and independent security review remain operator/release work. Saved research snapshots can retain previously uploaded content after its original is deleted.

Computer control, generated-code execution, live outbound communications, purchases and external publication remain unavailable. No paid API, external deployment, public repository publication or business message was initiated.
