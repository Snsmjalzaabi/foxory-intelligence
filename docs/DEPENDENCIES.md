# Dependency and license review — 2026-10-23

The original FOXORY source uses Apache-2.0. This does not relicense dependencies, container operating systems or model weights. `dependency-inventory.json` records 44 installed Python runtime packages and 179 npm manifests (including build/test dependencies), with their declared license metadata. `../THIRD_PARTY_NOTICES.txt` preserves bundled package license and notice texts found in those installations. The npm lockfile and Python runtime resolution lock record tested versions; Python lock hashes and an image-level SBOM remain follow-up release gates.

Preliminary review: FastAPI, SQLAlchemy, Alembic, React, Vite, react-markdown and python-docx declare permissive MIT terms; pypdf declares BSD-3-Clause; openpyxl MIT; Lucide ISC; highlight.js BSD-3-Clause. Most transitive code is permissively licensed. Relevant exceptions include **psycopg / psycopg-binary LGPL-3.0** and **certifi MPL-2.0**. Binary wheels may bundle additional libraries (libpq/OpenSSL and others) with their own notices. Dynamic use does not relicense FOXORY source, but redistribution must preserve notices and meet applicable license, source/relinking and modification obligations. Do not describe a container as containing only Apache-licensed code.

Executed security advisory checks: `npm audit --json` returned zero known advisories for the resolved frontend graph. `pip-audit -r requirements.lock --no-deps --disable-pip` returned zero known advisories for 44 pinned runtime packages. These are dated advisory lookups, not proof of security. System/image CVE scanning and independent review are outstanding.

Container review is incomplete: PostgreSQL's database license is permissive; Ollama declares MIT for its own code; Debian images include separately licensed packages. Images are version-tagged, not digest-pinned. Release packaging must retain OS notices, generate a container SBOM, review linked native libraries, pin image digests and verify source-availability obligations. Do not publish a release before that review.

No model weights are included in the repository or image. Users explicitly select/download models and must review the exact model's license, base-model restrictions and intended-use constraints. Licenses vary within model families. Hardware suggestions are not license clearance or measured compatibility. No third-party artwork, copied interface, private configuration or undocumented service API is included.

Live test model: downloaded `qwen2.5:0.5b` in a private local Ollama volume for CPU connectivity verification. `ollama show --license` identified Apache License, Version 2.0. Model weights are not committed or included in the FOXORY application image. This does not clear other model-family variants.
